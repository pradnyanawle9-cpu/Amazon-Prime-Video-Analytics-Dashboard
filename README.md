# Amazon Prime Video Content Analytics Dashboard

An interactive Power BI dashboard built to analyze and visualize Amazon Prime Video content using a dataset of 9,668 titles.

## 📊 Project Overview

This project transforms raw Amazon Prime Video data into an interactive dashboard that provides insights into content distribution, release trends, ratings, and genres.

The dashboard was designed to make the data easy to explore and communicate through clear KPIs and visualizations.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis (EDA)

## 📌 Dashboard Highlights

The dashboard includes:

- Total number of titles
- Total Movies and TV Shows
- Movies vs TV Shows distribution
- Titles released over the years
- Rating distribution
- Top 5 genres
- Interactive visual analysis

## 🔍 Key Insights

- Total titles analyzed: **9,668**
- Movies: **7,814 (80.82%)**
- TV Shows: **1,854 (19.18%)**
- The dataset contains significantly more Movies than TV Shows.
- Content additions increased considerably in recent years.
- **13+** is the most common rating category in the dataset.
- **Drama** is among the most represented genres.
